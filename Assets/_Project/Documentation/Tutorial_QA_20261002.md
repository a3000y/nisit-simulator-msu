# ผลทดสอบ 00_Tutorial — 2 ตุลาคม 2026

เมนู: Assets/Scenes/Scene1.unity

สิ่งที่เพิ่ม:
- ฉากฝึกหน้ามหาวิทยาลัย 7 ขั้น พร้อมจุดเดิน จุดโต้ตอบ และกิจกรรมเรียน/อาหาร/พักผ่อน
- ใช้ PlayerMovement, PlayerInteraction, IsometricCameraRig, ActivityStation, HUD, PhoneController, PauseMenu และแผนที่เดิม
- คณะที่รองรับหลักสูตร ใช้ CourseRegistrar และ RegistrationUI แยกในฉากฝึก และต้องเปิดแท็บตารางเรียนจริง
- เริ่มเกมใหม่เข้าสอนก่อน 01_Gameplay; โหลดเซฟยังเข้าเกมเดิม
- ปุ่มย้อนกลับ ถัดไป ข้าม ความคืบหน้า และสอนซ้ำจากเมนู
- สอนซ้ำจบหรือออกแล้วกลับเมนู เพื่อรักษาช่องเซฟ
- PlayerPrefs nisit_tutorial_status: 1 = ผ่าน, 2 = ข้าม; เชื่อม tut_seen กับหน้าช่วยเหลือ F1 เดิม
- กัน SaveManager.Save และ SaveSystem.Save/DeleteSave/DeleteSlot ในฉากฝึก
- ฉากฝึกไม่มี GameplayBootstrap และไม่สร้างข้อมูลลงทะเบียน ไอเท็ม หรือเงินในเซฟจริง
- เพิ่ม Scene ใน Build Settings โดยเก็บ 3 Scene เดิมและลำดับเดิมไว้

ผลทดสอบอัตโนมัติใน Play Mode:
ผ่าน — เมนูเริ่มเกมใหม่ → ช่องเซฟ → แต่งตัว → คณะ → 00_Tutorial
ผ่าน — ถัดไปไม่ข้ามขั้นเดินที่ยังไม่สำเร็จ
ผ่าน — CharacterController เดินถึงเป้าหมาย และการเปลี่ยน yaw กล้องทำให้ขั้นเดินสำเร็จ
ผ่าน — PlayerInteraction ตรวจพบป้ายและ ActivityStation ในระยะจริง
ผ่าน — ป้ายต้อนรับโต้ตอบสำเร็จแล้วจึงไปต่อได้
ผ่าน — ย้อนกลับและกลับมาหน้าคำอธิบายได้
ผ่าน — เรียนผ่าน ActivityStation: พลังงาน 65 → 55, EXP 0 → 10
ผ่าน — กินผ่าน ActivityStation: ความอิ่ม 60 → 90
ผ่าน — พักผ่าน ActivityStation: พลังงาน 55 → 80, ความพึงพอใจ 50 → 60
ผ่าน — ขั้นกิจกรรมต้องทำครบทั้งสามประเภท
ผ่าน — โทรศัพท์ ปฏิทิน ภารกิจ แอปแผนที่ แผนที่ M และเมนูพักเกม/เล่นต่อทำงาน
ผ่าน — คณะที่ใช้หลักสูตร เปิดปฏิทินอย่างเดียวไม่ผ่านขั้นตารางเรียน; เปิด RegistrationUI แท็บ 1 จึงผ่าน
ผ่าน — ปุ่มเริ่มชีวิตนิสิตโหลด 01_Gameplay ผ่าน GameplayBootstrap/PlayerSpawnSystem เดิม
ผ่าน — เกมใหม่มี EXP 0, วัน 1, หน่วยกิตที่เลือก 0 และจุดเกิดหอพัก (1314.18, 0.74, 3.10)
ผ่าน — เงินเกมใหม่ 200 ตรงกับ DailyAllowance 100 + โบนัส New Game+ เดิม 100; ไม่พกเงินฝึก 100 ไปเพิ่ม
ผ่าน — ไม่มี OnboardingTutorial เหลือใน Gameplay; ผู้เล่น กล้อง MainCamera และ EventSystem อย่างละหนึ่ง
ผ่าน — ข้ามจากหน้าต้อนรับเข้าสู่เกมใหม่ และบันทึกสถานะ 2
ผ่าน — เปิดสอนซ้ำจากปุ่มเมนู เริ่มขั้น 1/7 ด้วยข้อมูลฝึกใหม่ และออกกลับเมนูได้
ผ่าน — ทดสอบเส้นทางจบสอนซ้ำกลับเมนู โดยตรวจ Replay ก่อนเรียก Finish(false)
ผ่าน — โหลดข้อมูลทดสอบผ่าน MainMenuController.Continue โดยไม่ผ่าน Tutorial: EXP 17 และเงิน 323 คืนตรงเซฟ
ผ่าน — เปิดหน้า LoadSaveScreen จากปุ่มโหลดเซฟได้
ผ่าน — ตรวจ hash เซฟจริงทั้ง 3 ช่องก่อน/หลังทั้งหมด: ไม่เปลี่ยน
ผ่าน — Console รอบสุดท้าย: 0 Error, 0 Warning
ผ่าน — ตรวจ UI ทั้ง 7 หน้าและภาพ 1280×720; TMP ไม่รายงาน text overflow

ขอบเขตการทดสอบ:
- ตรวจปุ่มจากสคริปต์จริง และทดสอบการเคลื่อนที่/กล้องผ่าน API ของระบบเดิม
- โต้ตอบผ่านเป้าหมายที่ PlayerInteraction ตรวจพบ แล้วเรียก IInteractable.Interact
- กดปุ่ม UI ผ่าน onClick และทดสอบ Pause ผ่านเมธอดเดิม ไม่ได้จำลองการกดคีย์บอร์ดหรือเมาส์ของผู้เล่นจริง
- ใช้เซฟ QA แยกใน TutorialBackups/20261002/qa-save.json ไม่เขียนเซฟจริง
- เส้นทาง Continue ทดสอบผ่านเมธอด Continue หลังเปิดหน้าโหลด ไม่ได้ทดสอบการเลือกแถวเซฟจริง
- ภาพรอบสุดท้ายถ่ายจาก Play Mode โดยเลือกหน้าเพื่อแสดง UI; การตรวจขั้นฝึกจริงแยกทดสอบตามรายการข้างต้น
- ยังไม่ได้ทดสอบในตัวเกมที่ Build ออกมา หรือทดสอบการเล่นด้วยมือ
- คืน PlayerPrefs การผ่าน/ข้ามจากการทดสอบกลับค่าก่อนทดสอบแล้ว
