# อาคารคณะวิทยาศาสตร์ มมส — ผังล้อมลานหญ้า

สร้างในฉาก `Assets/_Project/Scenes/01_Gameplay.unity` ของโปรเจกต์ Unity เดิม

- Prefab: `Assets/_Project/Prefabs/ScienceFaculty/MSU_Science_Faculty.prefab`
- กลุ่มในฉาก: `MSU_Science_Faculty` ตำแหน่ง `(78, 0, -64)` หมุนแกน Y 180 องศา
- ตัวอาคาร 36 × 24 เมตร สูง 4 ชั้น ล้อมลานหญ้าเปิดโล่ง 20 × 12 เมตร
- มุมบนใน `floor-plan.png`: ทางเข้าใหญ่ด้านล่าง ทางเข้าอื่นด้านซ้าย ขวา และบน
- ชั้น 1: โถงต้อนรับและพักคอย ห้องเรียน 2 ห้อง แล็บ 2 ห้อง ทางเดินรอบลาน และประตูห้องกว้าง 2.2 เมตร
- ชั้นบนเป็นเปลือกอาคารและพื้นที่ชนแบบทึบ ไม่มีห้อง เฟอร์นิเจอร์ บันได หรือลิฟต์
- ระบบ BuildingRoofHider เดิมเปิดมุมมองชั้น 1 เมื่อตัวละครอยู่ภายใน โดยไม่ปิด Collider
- ใช้ Prefab/โมเดลเดิม 354 ชิ้น จาก School, Synty, Classroom, ITBuilding, GEBuilding และ KayKit
- สำเนาวัสดุและ Mesh ที่ต้องปรับไว้ในโฟลเดอร์อาคารนี้ พื้นผิวอิฐใช้ภาพเดิมของ Synty
- ส่วนเสริมที่สร้างเฉพาะงานนี้ ได้แก่ หลังคาลาดแต่ละปีก ใบและลำต้นปาล์ม และทางลาด ไม่มีแพ็กใหม่

จัดกลุ่มโครงชั้น 1, ภายใน, เปลือกชั้นบน, เพดาน/ชายคา และภูมิทัศน์แยกไว้ใน Prefab

อาคารวิทยาศาสตร์เก่าและต้นไม้เดิมในพื้นที่ก่อสร้างเก็บไว้แบบไม่ Active โดยไม่ลบ ตำแหน่งเดิมและรายชื่ออยู่ใน `AssetSources.txt` ส่วนโคมไฟเดิมด้านหลังคงไว้ และปรับทางลาดใหม่ให้เชื่อมทางเดินก่อนถึงโคมไฟ

สำรองฉากก่อนสร้าง: `Assets/_Project/Scenes/Backups/ScienceFaculty_20261005_121231.unity`

## การตรวจสอบ

ทดสอบใน Play mode ด้วย Player และ CharacterController เดิม (ความสูงจริง 1.32 เมตร รัศมี 0.33 เมตร ระยะขึ้นขั้นบันได 0.198 เมตร) โดยคืนตำแหน่งและสถานะตัวละครหลังตรวจ

ผล 47 ผ่าน, 0 ไม่ผ่าน: เข้าออกทั้ง 4 ด้าน ทางลาด ทางเดินรอบลาน ห้องเรียนและแล็บ ทางเดินระหว่างเฟอร์นิเจอร์ พื้นรับตัวละครตก ผนัง/กระจก/ผนังกั้นป้องกันการทะลุ เพดานและชั้นบนปิดการเข้าถึง ลานกลางเปิดถึงท้องฟ้า และระบบซ่อนหลังคา รายละเอียดอยู่ใน `validation.txt`

ภาพ `exterior.png`, `interior.png` และ `floor-plan.png` เรนเดอร์จาก Prefab ที่บันทึกจริง โดยภาพภายในและผังซ่อนเฉพาะเปลือกชั้นบน/เพดานเพื่อแสดงชั้น 1

เมนู `Nisit > Science Faculty > Build New` และ source ใน `Assets/_Project/Scripts/Editor/ScienceFacultyBuilder.cs` เก็บไว้สำหรับศึกษาการประกอบ เมนูป้องกันการเขียนทับอาคารที่มีแล้ว ใช้ Prefab ที่บันทึกไว้เมื่อต้องการนำไปใช้ซ้ำ
