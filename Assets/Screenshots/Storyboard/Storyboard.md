# Storyboard — Nisit Simulator (ลำดับตั้งแต่เมนูหลักถึงเล่นจริงในมหาวิทยาลัย)

ภาพทั้งหมดถ่ายจาก Game View จริงของโปรเจกต์ (PNG 1920×1080) ผ่าน Unity MCP — ไม่มีการวาดใหม่ ไม่ใช้ภาพ AI ไม่แก้ข้อความ/ค่าสถานะ

![Contact sheet](Storyboard_ContactSheet.png)

> **หมายเหตุการทดสอบ (Test data):** การกดปุ่ม/วาร์ปผู้เล่น/เร่งเวลา ในรอบถ่ายนี้สั่งผ่านสคริปต์ (Unity MCP) ไม่ใช่การกดคีย์จริง จึงระบุคีย์จริงของเกมไว้ในช่อง "ผู้เล่นต้องทำ" และเวลาในเกมบางเฟรมถูกตั้งเพื่อให้แสงสม่ำเสมอ การบันทึกระหว่างถ่ายถูกชี้ไปไฟล์ทดสอบแยก (sandbox) ไม่ได้แตะเซฟจริง

## ข้อจำกัด / สิ่งที่ไม่รองรับ (รายงานตามจริง)

- ไม่มีขั้น "โทรศัพท์ (ตารางเรียน/ภารกิจ/แผนที่)" ภายในบทแนะนำ (00_Tutorial) ให้แยกเป็นเฟรมของมันเอง จึงใช้เหตุการณ์ที่มีอยู่จริงแทน คือ SB_17 (เปิดโทรศัพท์ในเกมจริง) และภาพละเอียดแต่ละแอปอยู่ใน `UI/UI_Phone_*.png` + `UI_Timetable_Practice.png` (ตารางเรียนช่วงฝึก)
- ปุ่ม "ลงทะเบียนเรียน" ในโทรศัพท์ใช้ได้เฉพาะหลักสูตรสายคอมพิวเตอร์ (CS); ตัวละครทดสอบเป็นคณะ IT เกมจึงแสดงข้อความ "ไม่ต้องลงทะเบียน" และตารางเรียนว่าง (`UI_Registration.png`, `UI_Registration_Timetable.png`) — ไม่ได้ปลอมข้อมูลเพื่อให้ดูมีวิชา
- ภารกิจวันนี้ว่าง และรายชื่อเพื่อนว่าง เพราะเป็นสถานะตั้งต้นของเซฟทดสอบ
- มีมากกว่า 12 เฟรม (17 เฟรม) เพราะบทแนะนำแยกเป็นหลายขั้นตอนจริง
- ปัญหาที่พบระหว่างถ่าย (ไม่ได้แก้ในเกม): ปุ่ม "ลงทะเบียนเรียน" บนโทรศัพท์ตัวอักษรตกบรรทัด/ล้นปุ่ม, หน้าร้านอาหารชื่อและรายละเอียดเมนูเป็นสีม่วงเข้มบนการ์ดสีเทาเข้ม อ่านยาก, เสา FrontColumn ของโรงอาหารกลางไม่มี Material (แสดงเป็นสีม่วงแดง), และใน session ที่สลับฉากด้วยสคริปต์ HUDController.Instance เป็น null ทำให้ป้าย "กด E" ไม่ขึ้นจนกว่าจะตั้งค่า Instance ใหม่ (ต้องลองซ้ำด้วยการเล่นจริง)
