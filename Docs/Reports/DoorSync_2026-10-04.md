## ระบบที่เพิ่ม

DoorSyncManager บน NetworkObject เดิมของ LobbyState ถือ NetworkVariable ulong สองชุด รองรับ 128 บาน Host เท่านั้นเขียนสถานะ มี catalog ของ path ใต้อาคารและ fingerprint ให้ทุกเครื่องใช้ ID ตรงกัน ใช้ RPC ขอ toggle จาก Client โดยอ่านผู้ส่งจาก NGO แล้วตรวจ connected, phase, ID, catalog, sequence, ตำแหน่งที่ Host รับผ่าน NetworkAvatar, ระยะ interact และคำขอซ้ำ/ติดกันภายใน 0.15 วินาที

เกม Multiplayer ใหม่ปิดทุกบานของสามอาคารโดยไม่เปลี่ยน startOpen ของ GE/IT ใน prefab ของโหมดเล่นคนเดียว การนอนคงสถานะเดิม ชุดประตูนี้ยังไม่มีการบันทึกสถานะประตูลง JSON เดิม จึงไม่มีการเพิ่มการคืนประตูจาก Continue ในงานนี้ การตรวจระยะป้องกัน RPC ที่เปลี่ยนประตูไกล ๆ แต่ยังใช้ตำแหน่ง avatar ที่ owner ส่งมา ไม่ใช่ระบบป้องกันโกงการเคลื่อนที่เต็มรูปแบบ

แก้ GEDoor ให้ใช้ unscaledDeltaTime เฉพาะประตู Multiplayer เพราะตอนพักเกมค่า bool ซิงก์ได้แต่ hinge เดิมใช้ deltaTime=0 แล้วหยุดหมุน โหมดเล่นคนเดียวยังใช้เวลาเดิม

หลังรายงานขั้นที่ 0 ใน run8 และการอนุมัติให้ทำหอพัก/GE/IT แก้ prefab เครือข่าย LobbyState เพื่อเพิ่ม manager เพียงตัวเดียว ไม่แก้ prefab ประตู/อาคารหรือ Scene ระหว่างทดสอบ เครื่องมือ BuildMPTest รุ่นสุดท้ายไม่มีขั้นตอนบันทึก prefab; ระบบตรวจอนุมัติปฏิเสธการ build ที่บันทึก prefab ซ้ำครั้งหนึ่ง จึงเอาขั้นตอนนั้นออกแล้ว build สำเร็จ

## สิ่งที่ยังไม่ได้ทดสอบจริง

- ⏳ LAN หลายเครื่อง, Relay, latency/jitter/packet loss จำลอง และ WAN
- ⏳ คีย์บอร์ด E จริงพร้อมกันสองคน; รอบนี้ใช้ Interact และวัด RPC ใน Host frame เดียวกัน
- ⏳ เดินเส้นทางต่อเนื่องทั้งหมดโดยไม่ย้ายตำแหน่ง และทุกโมเดลตัวละคร/ขนาด CC; พบปัญหาทางออกข้าง IT แล้วจึงต้องตรวจโมเดลเพิ่ม
- ⏳ Client ทั้งสองกลับเมนูพร้อมกันเมื่อ Host ออก; รอบนี้ C2 crash แล้ว วัด C1 ที่ยังเชื่อมอยู่
- ⏳ late join ระหว่างอยู่ใน Gameplay (นอกเหนือจากออก/เข้า Lobby ก่อนเริ่มที่วัดแล้ว)
- ⛔ ฟิสิกส์อิสระของ NetworkAvatar ซึ่งเดิมปิด Collider
- ⏳ door persistence ใหม่ใน Continue ถ้าจะเพิ่มในอนาคต; ปัจจุบันไม่มี door state save เดิมให้คืน
- ⏳ การแก้ SideExit geometry และ achievement persistence ตามข้อเสนอ ยังไม่ได้ลงมือ

ผลรายงานยืนยันเฉพาะสิ่งที่วัดข้างต้น ไม่ใช้ผล EditMode แทนการวัดเครือข่ายหรือฟิสิกส์จริง
